# 📚 LitFeed

> **Conectando leitores através de histórias.**

O **LitFeed** é uma plataforma web voltada para leitores que combina organização de leituras com interação social. O projeto surgiu como uma iniciativa de aprendizado prático, reunindo funcionalidades inspiradas em plataformas como **Skoob** e **Maratona de Leitura** em uma experiência única e moderna.

O principal objetivo do projeto é aprofundar conhecimentos em desenvolvimento **Full Stack**, explorando tecnologias modernas e boas práticas de Engenharia de Software durante a construção de uma aplicação completa.

---

# ✨ Funcionalidades

- 👤 Cadastro e autenticação de usuários
- 📚 Biblioteca pessoal
- 📖 Registro e acompanhamento de leituras
- ⭐ Avaliações e resenhas
- 📰 Feed de publicações
- ❤️ Curtidas, comentários e compartilhamentos
- 👥 Sistema de seguir usuários
- 📋 Listas personalizadas
- 🎨 Perfil personalizável
- 📊 Estatísticas de leitura
