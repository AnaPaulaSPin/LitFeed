# Requisitos Funcionais (RF)

Os requisitos funcionais descrevem as funcionalidades que o LitFeed deverá oferecer aos usuários, abrangendo os módulos de gerenciamento de usuários, biblioteca, livros, interação social, feed e configurações da plataforma.

---

## 👤 Módulo de Usuários

### RF01 – Cadastro de Usuários

O sistema deve permitir o cadastro de usuários.

### RF02 – Autenticação de Usuários

O sistema deve permitir a autenticação (login) de usuários.

### RF03 – Encerramento de Sessão

O sistema deve permitir o encerramento da sessão (logout).

### RF04 – Recuperação de Senha

O sistema deve permitir a recuperação de senha.

### RF05 – Edição do Perfil

O sistema deve permitir a edição das informações do perfil.

### RF06 – Personalização do Perfil

O sistema deve permitir a personalização da foto de perfil e do banner.

### RF07 – Configuração de Privacidade

O sistema deve permitir configurar a privacidade do perfil.

### RF08 – Visualização de Perfis

O sistema deve permitir visualizar o próprio perfil e o perfil de outros usuários.

---

## 📚 Módulo de Biblioteca

### RF09 – Adicionar Livros

O sistema deve permitir adicionar livros à biblioteca do usuário.

### RF10 – Remover Livros

O sistema deve permitir remover livros da biblioteca.

### RF11 – Alterar Status de Leitura

O sistema deve permitir alterar o status de leitura de um livro.

### RF12 – Registrar Progresso

O sistema deve permitir registrar o progresso da leitura.

### RF13 – Criar Listas Personalizadas

O sistema deve permitir criar listas personalizadas de livros.

### RF14 – Organizar Livros em Listas

O sistema deve permitir adicionar um mesmo livro a diferentes listas personalizadas.

### RF15 – Estatísticas de Leitura

O sistema deve permitir visualizar estatísticas básicas de leitura.

---

## 📖 Módulo de Livros

### RF16 – Informações dos Livros

O sistema deve exibir informações detalhadas sobre um livro.

### RF17 – Avaliação de Livros

O sistema deve permitir avaliar livros.

### RF18 – Criação de Resenhas

O sistema deve permitir criar resenhas.

### RF19 – Registro de Releituras

O sistema deve permitir registrar releituras de um mesmo livro.

### RF20 – Gerenciamento de Resenhas

O sistema deve permitir editar ou excluir resenhas criadas pelo próprio usuário.

---

## 📰 Módulo Social

### RF21 – Criar Publicações

O sistema deve permitir criar publicações.

### RF22 – Gerenciar Publicações

O sistema deve permitir editar e excluir publicações próprias.

### RF23 – Associação com Livros

O sistema deve permitir associar uma publicação a um livro (opcional).

### RF24 – Curtidas

O sistema deve permitir curtir publicações.

### RF25 – Comentários

O sistema deve permitir comentar publicações.

### RF26 – Compartilhamentos

O sistema deve permitir compartilhar publicações.

### RF27 – Seguidores

O sistema deve permitir seguir e deixar de seguir outros usuários.

---

## 🌎 Módulo Feed

### RF28 – Exibição do Feed

O sistema deve exibir um feed de publicações.

### RF29 – Personalização do Feed

O sistema deve personalizar o feed conforme os interesses do usuário.

### RF30 – Recomendação de Conteúdos

O sistema deve recomendar conteúdos relacionados aos hábitos de leitura do usuário.

### RF31 – Pesquisa

O sistema deve permitir pesquisar livros, usuários e publicações.

---

## ⚙️ Módulo de Configurações

### RF32 – Gerenciamento da Conta

O sistema deve permitir alterar informações da conta.

### RF33 – Preferências da Plataforma

O sistema deve permitir gerenciar preferências da plataforma.

### RF34 – Visibilidade das Publicações

O sistema deve permitir configurar a visibilidade das publicações.

### RF35 – Exclusão da Conta

O sistema deve permitir excluir a conta do usuário.
